## Description

Project convention: every user-facing feature has a runnable example in `examples/`.
HITL is the feature most in need of one, because the checkpointer-ownership subtlety
is not discoverable from the API surface — a user who defaults one in and then
deploys to LangGraph Platform will find it silently ignored.

Build `examples/human_in_the_loop/` showing the structural gate: read-only tools run
freely, write tools route to an approval node.
