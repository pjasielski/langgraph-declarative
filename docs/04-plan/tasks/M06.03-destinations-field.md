## Description

An approval node routes itself by returning `Command(goto=...)` and therefore has no
static outgoing edges. `_add_nodes` calls `graph.add_node(node.name, fn)` with no
`destinations=`, so LangGraph cannot know where the node leads.

The consequence is worse than missing edges. Verified on LangGraph 1.2.2, a
`Command(goto=...)` node without `destinations` renders:

```
__start__ --> approval;
approval --> __end__;     # <-- wrong: approval never goes to END
```

An actively misleading diagram, on what is a headline feature of this library.
With `destinations=('execute','agent')` the spurious edge disappears.

Add an optional `destinations:` list to the node schema and forward it.

```yaml
nodes:
  - name: approval
    function: approval
    destinations: [execute, agent]   # no static edges; routes via Command
```
