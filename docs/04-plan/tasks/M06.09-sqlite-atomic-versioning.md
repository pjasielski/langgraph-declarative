## Description

`SQLiteLoader.save()` reads `MAX(version)` and inserts in a separate statement.
Concurrent writers can pick the same version; one fails on the unique constraint.
The loader is a reference implementation, but it should not fail under a trivial
concurrent load.

## Acceptance Criteria

- [ ] Version allocated and inserted in one statement (`INSERT … SELECT COALESCE(MAX(version), 0) + 1 …`) inside `BEGIN IMMEDIATE`
- [ ] Connection opened with a busy `timeout`
- [ ] Threaded test: N concurrent `save()` calls produce N distinct consecutive versions, no exceptions
- [ ] Docstring states it is a reference/local implementation
