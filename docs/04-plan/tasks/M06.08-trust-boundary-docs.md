## Description

Two things are true but undocumented:

1. **Definitions are trusted input.** `yaml.safe_load` prevents object construction,
   but a definition can import any `module.path:attr` as a tool, read any reachable
   YAML via `imports:`/`subgraph:`, and select any registered callable. Fine for
   repository-controlled files; unsafe for user uploads.
2. **HITL primitives are not an approval system.** The library passes the checkpointer
   through. The host owns thread IDs, who may resume, decision validation, stale
   decisions, and audit. `interrupt_before` creates a pause, not an authorization
   check. `destinations` is diagram metadata, not enforcement.
