## Description

The README says the schema "ships at `schema/workflow.schema.json`", but the 0.2.0
wheel contains only Python modules — the file exists in the sdist and the repo, not
in an installed package. There is no `py.typed`, so downstream type checkers ignore
the annotations. Nothing tests the installed wheel, which is how this drift went
unnoticed.

## Acceptance Criteria

- [x] Schema shipped as package data (e.g. `src/langgraph_declarative/workflow.schema.json`) and readable via `importlib.resources`
- [x] A test asserts repo copy == packaged copy == `export_json_schema()`
- [x] `py.typed` marker included in the wheel
- [x] CI job: `uv build` → install the wheel in a clean venv → import, read the packaged schema, run the quickstart example
- [x] README states where the schema lives in an installed package
