## Description

`compile()` also accepts a `store`, LangGraph's cross-thread memory primitive
(the checkpointer is per-thread; the store spans threads). Since M06.01 already
opens the same call path, adding `store` alongside it is nearly free and closes the
persistence surface completely.

Lowest priority in the milestone — additive, not required for HITL to work. Drop it
without hesitation if the milestone needs trimming.

## Acceptance Criteria

- [ ] `store` accepted as a keyword-only argument on `build_graph()`, `GraphBuilder.__init__`, and `build_graph_from_db()`
- [ ] Forwarded to the top-level `compile()`; not passed to nested subgraph compiles (same rule as the checkpointer, ADR-005)
- [ ] Never defaulted — same reasoning as ADR-004
- [ ] Omitting it leaves the `compile()` call unchanged
- [ ] Smoke test: a store passed in is reachable from a node via the injected runtime
