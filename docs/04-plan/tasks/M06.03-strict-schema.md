## Description

No config model sets `extra="forbid"`, and `test_extra_unknown_fields_are_ignored`
locks in the permissive behaviour. Reproduced: `tool:`, `temprature:` and
`interupt_before:` all validate cleanly and do nothing. With HITL, a typo in
`interrupt_before` silently removes an approval gate.

Decision (session 013): reject unknown keys everywhere. Add an explicit optional
`description:` (graph, node, edge) so documentation keys stay legal. See ADR-007.

## Acceptance Criteria

- [ ] Shared strict base model (`ConfigDict(extra="forbid")`) used by every config model, including `StateFieldConfig` and `LLMConfig`
- [ ] Optional `description: str` on graph, node and edge
- [ ] Unknown-key errors name the key and the location, with a closest-match suggestion where one exists
- [ ] `test_extra_unknown_fields_are_ignored` replaced by tests asserting rejection
- [ ] All `tests/fixtures/*.yaml`, examples and `template/` still validate
- [ ] `schema/workflow.schema.json` regenerated (`additionalProperties: false`)
- [ ] CHANGELOG lists the breaking change
