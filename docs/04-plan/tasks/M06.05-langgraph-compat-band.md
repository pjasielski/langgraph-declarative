## Description

`pyproject.toml` declares `langgraph>=0.2`, but CI only tests the lockfile (1.2.2).
Measured in session 013 with the full suite:

| LangGraph | Result |
|---|---|
| 0.2.0 | test collection fails (`langgraph.types`, `InMemorySaver` missing) |
| 0.2.76 / 0.3.34 | 2 HITL tests fail |
| 0.4.10, 0.6.11, 1.0.10, 1.2.2 | all pass |

Decision (session 013): declare `langgraph>=1.0` — one readable floor on LangGraph's
stable line, no upper cap. The "latest" CI job catches a future major. See ADR-008.
