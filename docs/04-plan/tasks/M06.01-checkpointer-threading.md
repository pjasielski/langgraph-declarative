## Description

The library cannot express human-in-the-loop because no parameter on the call chain
reaches `graph.compile()`. `interrupt()` pauses a graph by persisting state at the
pause point, and that persistence *is* the checkpointer — without one, a pause cannot
be resumed and there is no `thread_id` scoping.

Add an optional, caller-supplied `checkpointer` to every public entry point and pass
it to the single top-level `compile()` call.

**Do not default it.** Ownership flips by run mode: under `langgraph dev` /
LangGraph Platform the server owns the checkpointer and one passed at compile time
is silently ignored. Defaulting to `InMemorySaver` would look like it worked while
doing nothing — worse than today's honest failure. See ADR-004.

**Do not pass it to nested subgraph compiles.** Verified on LangGraph 1.2.2: a
subgraph compiled without a checkpointer still interrupts and resumes correctly when
the parent has one. See ADR-005.

## Acceptance Criteria

- [ ] `build_graph(path, registry, state_class=None, *, checkpointer=None)` accepts and forwards it
- [ ] `GraphBuilder.__init__(registry, state_class=None, *, checkpointer=None)` stores it
- [ ] `_build()` ends with `graph.compile(checkpointer=self.checkpointer)`
- [ ] `build_graph_from_db(...)` accepts and forwards `checkpointer` (fourth entry point — not named in the handoff, found during exploration)
- [ ] `draw_mermaid(...)` still works — it compiles internally and must not break
- [ ] Nested subgraph compiles in `_add_nodes` receive **no** checkpointer
- [ ] Omitting `checkpointer` compiles with `checkpointer=None` — byte-for-byte current behaviour
- [ ] Existing test suite passes unchanged (`uv run pytest`)
- [ ] Keyword-only (`*`) so positional-arg call sites cannot silently shift
