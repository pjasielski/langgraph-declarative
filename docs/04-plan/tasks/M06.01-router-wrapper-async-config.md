## Description

`_wrap_mapped_router()` calls `router_fn(state)` synchronously and hides the router's
signature from LangGraph. Two reproduced failures:

- `async def` router with `targets:` → `ConfigValidationError: Router 'rt' returned
  coroutine` plus an un-awaited-coroutine warning.
- `def rt(state, config)` with `targets:` → `TypeError: rt() missing 1 required
  positional argument: 'config'`.

Dynamic routers (no `targets:`) are passed to LangGraph unwrapped and work. Mapped
routers must behave the same way: the wrapper validates the returned key without
changing how LangGraph invokes the function.

## Acceptance Criteria

- [ ] Coroutine routers get an `async` wrapper that awaits the result before validating
- [ ] The wrapper forwards LangGraph-injected parameters (`config`, runtime) — e.g. by mirroring the wrapped function's signature
- [ ] Key validation (non-string / unmapped key) is shared by the sync and async paths, with unchanged error messages
- [ ] Tests: sync, async, `config`-taking, async + `config` — all via `ainvoke`/`invoke` on a built graph
- [ ] Existing routing tests pass unchanged
