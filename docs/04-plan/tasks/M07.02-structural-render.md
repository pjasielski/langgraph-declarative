## Description

`draw_mermaid()` fully builds the graph, so rendering a diagram calls `create_llm()`
for every LLM node — it needs provider packages and possibly API keys just to draw
topology. Rendering should never construct runtime resources.

## Acceptance Criteria

- [ ] `draw_mermaid()` and `GraphBuilder.draw_mermaid()` build structurally: no `create_llm`, no tool resolution, no checkpointer/store
- [ ] Diagram output is identical to today's for graphs without LLM nodes
- [ ] Test: an LLM-node graph renders with no provider package importable
- [ ] Subgraphs render the same way
