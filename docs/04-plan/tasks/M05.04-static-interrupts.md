## Description

`interrupt_before` is the static alternative to calling dynamic `interrupt()` inside
a node function, and it is trivially expressible in YAML — which arguably makes it
the more natural fit for a declarative library. It lets a user add an approval pause
with no Python change at all.

```yaml
interrupt_before: [approval]
interrupt_after: []
```
