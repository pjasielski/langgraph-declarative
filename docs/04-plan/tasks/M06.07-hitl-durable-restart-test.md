## Description

HITL tests use `InMemorySaver`, which proves the API, not recovery. The point of a
checkpointer is surviving a process boundary. Add a test with a persistent saver that
rebuilds the graph from YAML between pause and resume, and asserts the side effect
happens exactly once.
