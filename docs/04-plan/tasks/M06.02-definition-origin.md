## Description

Relative paths resolve against the wrong directory in two cases:

1. **Imported nodes.** `_resolve_imports()` loads `lib/nodes.yaml` relative to the
   root file but copies only the `NodeConfig`s into the root config. If an imported
   node declares `subgraph: sub/child.yaml`, `_add_nodes()` resolves it against the
   root file's directory → `ConfigLoadError: Config file not found` (reproduced).
2. **In-memory / DB builds.** `GraphBuilder.build(config)` and
   `build_graph_from_db()` use `Path.cwd()`, so the same stored definition behaves
   differently depending on where the process starts.

Decision (session 013): every relative path resolves against the file that declares
it. In-memory and DB builds take an explicit keyword `base_dir=`. If a definition
without a file origin uses a relative `imports:`/`subgraph:` and no `base_dir` is
given, raise `ConfigValidationError` (breaking, 0.x). See ADR-009.

## Acceptance Criteria

- [x] `GraphBuilder.build(config, *, base_dir=None)` and `build_graph_from_db(..., base_dir=None)` accept a base directory
- [x] A relative `imports:`/`subgraph:` with no file origin and no `base_dir` raises `ConfigValidationError` with a message naming `base_dir`
